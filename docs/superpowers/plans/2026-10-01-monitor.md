# Karta budowania „Monitor” — plan wdrożenia

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Wdrożyć kierunek „Monitor” ze specyfikacji `docs/superpowers/specs/2026-10-01-monitor-design.md`: koncept monitora na całej karcie, bento w wyróżnionych, zrzuty w oknach z wykrywaniem jasnych, oś czasu jako zwarty dziennik z „więcej”.

**Architecture:** Strona bez build stepu: `index.html` + `css/main.css` + `js/main.js` (renderuje z `js/projects-data.js`) + `js/i18n.js` (nadpisuje dane i daje `window.__t` przed `main.js`). Zmiany wizualne w CSS, struktura kart w `main.js`, dwa nowe napisy w `i18n.js`. Muzeum i Kosmos nietknięte.

**Tech Stack:** HTML, CSS (grid, `-webkit-line-clamp`, `color-mix`, maski), vanilla JS, canvas 2D do pomiaru jasności. Weryfikacja: Playwright MCP na `python3 -m http.server` (konfiguracja `omniportfolio` w `.claude/launch.json`, port 8901).

## Global Constraints

- Bursztyn `--pulse` (#F2C46D) to jedyny kolor interakcji; kolory kategorii tylko jako kropki.
- Mono tylko dla dat, liczb i etykiet; tagi, filtry i nazwy kategorii zwykłym krojem bez wersalików.
- Okładki AI bez okna, z podpisem „wizualizacja AI”; prawdziwe zrzuty w oknie z trzema kropkami.
- Próg jasnego zrzutu: średnia luminancja > 0,55 z miniatury 32×20.
- Opis na osi czasu: 2 linie; „więcej”/„mniej” tylko przy opisie, który się nie mieści; `aria-expanded` + `aria-controls`.
- Duże kafle: `featured` ≤ 3; przy ≤ 980 px duże tylko miejsca 1–2; przy ≤ 640 px jedna kolumna.
- Wysokość strony przy 1440 px < 25 000 px. Zero błędów w konsoli, zero 404, brak przewijania w bok przy 320 px. Kontrast tekstu ≥ 4,5:1.
- `prefers-reduced-motion`: kropka nagrywania nie pulsuje.
- Komentarze w kodzie po polsku, w stylu pliku (wyjaśniają „dlaczego”).

Zamień całą funkcję `obrazHTML` (razem z komentarzem nad nią) na:

```js
  /* ── Obraz projektu ──────────────────────────────────────────────────────
     Ścieżkę zna tylko obrazProjektu() z projects-data.js. Prawdziwy zrzut stoi
     w oknie aplikacji (pasek z trzema kropkami) — od ilustracji odróżnia go już
     kształt, zanim ktoś przeczyta podpis. Okładka AI zostaje bez okna, z podpisem

    const o = obrazProjektu(p);
    if (!o) return "";
    if (o.okladka) {
      return `<span class="${klasa} shot-okladka">
        <img src="${o.src}" alt="" width="${o.w}" height="${o.h}" loading="lazy" decoding="async">
        <span class="shot-znacznik">${t("ui.okladka", "wizualizacja AI")}</span>
      </span>`;
    }
    const alt = wstaw(t("ui.zrzut", "Zrzut ekranu: {t}"), { t: p.title }).replace(/"/g, "&quot;");
    return `<span class="${klasa} zrzut okno">
      <span class="okno-pasek" aria-hidden="true"></span>
      <img src="${o.src}" alt="${alt}" width="${o.w}" height="${o.h}" loading="lazy" decoding="async">
```

- [ ] **Step 4: `js/main.js` — wykrywanie jasnych zrzutów**

Pod `obrazHTML` dopisz:

```js
  /* Jasne zrzuty (białe interfejsy SaaS) wybijały dziury w ciemnej stronie. Strona mierzy
     je sama: miniatura 32×20 na canvas, średnia luminancja powyżej progu → klasa „jasny”
     i mocniejsze przygaszenie. Zmienia się tylko filtr, nie wymiary, więc nic nie skacze.
     Żadnej listy do pilnowania — nowy zrzut zostanie zmierzony przy pierwszym wczytaniu. */
  const PROG_JASNOSCI = 0.55;
  const probnik = document.createElement("canvas");
  probnik.width = 32; probnik.height = 20;

  function luminancja(img) {
    const x = probnik.getContext("2d", { willReadFrequently: true });
    x.drawImage(img, 0, 0, 32, 20);
    const d = x.getImageData(0, 0, 32, 20).data;
    let suma = 0;
    for (let i = 0; i < d.length; i += 4) suma += 0.2126 * d[i] + 0.7152 * d[i + 1] + 0.0722 * d[i + 2];
    return suma / (255 * (d.length / 4));
  }

  function oznaczJasne() {
    for (const img of document.querySelectorAll(".okno img")) {
      const sprawdz = () => {
        /* Obraz z innego źródła albo strona z file:// „brudzi” canvas i getImageData
           rzuca wyjątek — wtedy zostaje zwykłe przygaszenie, strona działa dalej. */
        try { if (luminancja(img) > PROG_JASNOSCI) img.closest(".okno").classList.add("jasny"); }
        catch (e) { /* bez pomiaru */ }
      };
      if (img.complete && img.naturalWidth) sprawdz();
      else img.addEventListener("load", sprawdz, { once: true });
    }
  }
```
