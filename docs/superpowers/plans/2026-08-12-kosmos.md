# Kosmos budowania — plan wdrożenia

> **Dla pracujących agentowo:** WYMAGANA PODUMIEJĘTNOŚĆ: użyj superpowers:subagent-driven-development
> (zalecane) albo superpowers:executing-plans, żeby wdrożyć ten plan zadanie po zadaniu.
> Kroki mają składnię pól wyboru (`- [ ]`) do śledzenia postępu.

**Cel:** Gra o locie rakietą po sześciu powłokach orbitalnych, na których stoi 49 projektów
autora jako sondy, wśród prawdziwych planet z map NASA i USGS oraz prawdziwych mgławic
ze zdjęć ESA/Hubble.

**Architektura:** Statyczna strona bez kroku budowania. `WebGPURenderer` z three.js 0.185.1
z automatycznym zapasem na WebGL 2, moduły ES wczytywane przez import mapę. Świat wyrasta
z `js/projects-data.js` — dane są jedynym źródłem prawdy, kod ich nie dubluje.

**Stos:** three.js 0.185.1 (`three/webgpu` + `three/tsl`), TSL, WebGPU z zapasem na WebGL 2,
zwykły CSS, zero npm.

## Ograniczenia globalne

- **Pliki nietykalne:** `index.html`, `museum.html`, `js/museum/**`, `js/main.js`,
  `js/projects-data.js`, `css/main.css`, `css/museum.css`. Muzeum i portfolio są wdrożone
  na żywej stronie publicznej.
- **Zero kroku budowania.** Statyczne HTML/CSS/JS, moduły ES przez import mapę, bez npm.
- **Zero importów z `js/groza/` i `js/museum/`.** Dzielimy dane, nie kod. Jedyny wspólny plik
  to `js/projects-data.js`, tylko do odczytu.
- **Uchwyt diagnostyczny to `window.__kosmos`.** Nigdy `window.__mz` ani `window.__groza`.
- **Klasy CSS z przedrostkiem `k-`**, żeby nic nie kolidowało z `css/museum.css` ani `css/main.css`.
- **Stempel wersji `?v=` w jednym miejscu** — w import mapie w `kosmos.html`, nie przy każdym imporcie.
- **Assety wyłącznie z jasną licencją**, każdy plik wpisany do `assets/kosmos/LICENSES.md`
  z adresem źródła. Zakaz assetów ze sklepu Unity.
- **Zero nazw klientów i pracodawców**, zero adresów IP i szczegółów infrastruktury,
  zero odnośników do prywatnych repozytoriów, zero liczników tokenów.
- **Bez `git push` i bez scalania do `main`.** GitHub Pages buduje z `main`, więc każde
  wypchnięcie jest wdrożeniem na żywo.
- **Rozmieszczenie deterministyczne.** Nigdy `Math.random()` — losowość wyłącznie z ziarna
  pochodzącego z `id` projektu, żeby ten sam projekt zawsze stał w tym samym miejscu.
- **Budżet `assets/kosmos/` ≤ 3 MB**, całe `assets/` ≤ 5 MB.

## Zasady weryfikacji obowiązujące w każdym zadaniu

1. **Playwright, nie wbudowany panel przeglądarki.** Panel zwraca rozmiar okna 0×0 i unieważnia
   każdy pomiar układu. Przed zaufaniem jakiemukolwiek pomiarowi sprawdź `innerWidth > 0`.
2. **Kontrola negatywna obowiązkowa.** Zanim uznasz test za dowód, cofnij poprawkę i sprawdź,
   czy test potrafi oblać. Test, który przechodzi także na zepsutym kodzie, nie jest dowodem.
   Cztery z pięciu usterek w planie poprzedniej gry siedziały w kodzie testów, nie w kodzie gry.
3. **Nie testuj sterowania przez `window.__kosmos`.** Kanał diagnostyczny nie zobaczy, że
   prawdziwa klawiatura jest zasłonięta. Używaj prawdziwych zdarzeń klawiatury i myszy.
4. **Wyłącz pamięć podręczną przy kontrolach negatywnych.** Moduł spod tego samego `?v=`
   potrafi zostać stary i zamienić kontrolę w fałszywie negatywną.
5. **Jeśli pomiar zwraca zero dla wszystkiego**, w tym dla rzeczy, o której wiesz, że istnieje —
   zepsuty jest przyrząd, nie dane. Ta pułapka wystąpiła trzykrotnie przy zbieraniu adresów
   do tego planu.

- [ ] **Krok 2: `js/kosmos/render.js`**

```js
/* Warstwa renderowania Kosmosu. WebGPU z automatycznym zapasem na WebGL 2.
   Kształt import mapy i wymóg await init() opisane w kosmos.html. */

import * as THREE from "three";

window.__bledy = [];
addEventListener("error", (e) => window.__bledy.push(String(e.message)));
addEventListener("unhandledrejection", (e) => window.__bledy.push(String(e.reason)));

const host = document.getElementById("scene-host");
const loader = document.getElementById("k-loader");

/* Wymuszenie WebGL służy WYŁĄCZNIE kontroli negatywnej w testach: ?webgl=1 w adresie
   ma przełączyć plakietkę na "WebGL 2". Bez tego nie da się udowodnić, że wykrycie
   backendu w ogóle działa, a nie zwraca na stałe jednej wartości. */
const WYMUS_WEBGL = new URLSearchParams(location.search).has("webgl");

const scene = new THREE.Scene();
scene.background = new THREE.Color(0x03050c);

const camera = new THREE.PerspectiveCamera(60, innerWidth / innerHeight, 0.5, 200000);
camera.position.set(0, 40, 260);

let renderer, backend;

try {
  renderer = new THREE.WebGPURenderer({ antialias: true, forceWebGL: WYMUS_WEBGL });
  renderer.setPixelRatio(Math.min(devicePixelRatio, 1.75));
  renderer.setSize(innerWidth, innerHeight);
  renderer.toneMapping = THREE.ACESFilmicToneMapping;
  renderer.toneMappingExposure = 1.0;

  /* KLUCZOWE: WebGPURenderer startuje asynchronicznie. setAnimationLoop() załatwiłby to
     sam, ale main.js prowadzi własną pętlę na requestAnimationFrame — bez tej linijki
     pierwsza klatka trafia w niezainicjowany renderer i ekran zostaje czarny
     BEZ błędu w konsoli, czyli w najgorszy możliwy do zdiagnozowania sposób. */
  await renderer.init();

  backend = renderer.backend.isWebGPUBackend ? "WebGPU" : "WebGL 2";
  host.appendChild(renderer.domElement);
} catch (e) {
  window.__bledy.push("renderer: " + e.message);
  document.getElementById("k-brak-webgpu").hidden = false;
  loader.classList.add("gotowe");
  throw e;
}

document.getElementById("k-backend").textContent = backend;

addEventListener("resize", () => {
  camera.aspect = innerWidth / innerHeight;
  camera.updateProjectionMatrix();
  renderer.setSize(innerWidth, innerHeight);
});

window.__kosmos = { renderer, scene, camera, backend };

export { renderer, scene, camera, backend, host, loader };
```

```js
import { renderer, scene, camera, loader } from "kosmos/render.js";

const probny = new THREE.Mesh(
  new THREE.BoxGeometry(40, 40, 40),
  new THREE.MeshBasicMaterial({ color: 0x5cc8db, wireframe: true })
);
probny.name = "probny";
scene.add(probny);
window.__kosmos.probny = probny;

loader.classList.add("gotowe");

const zegar = new THREE.Clock();
function petla() {
  requestAnimationFrame(petla);
  const dt = Math.min(zegar.getDelta(), 0.05);
  probny.rotation.y += dt * 0.6;
  renderer.render(scene, camera);
}
petla();
```

- [ ] **Krok 2: Sprawdź, że to naprawdę mapy równoodległościowe**

Mapa równoodległościowa ma proporcję dokładnie 2:1. Plik, który jej nie ma, nie owinie się
poprawnie na kuli — bieguny się rozjadą.

```bash
for f in *.jpg; do
  python3 - "$f" <<'PY'
import struct, sys
d = open(sys.argv[1], 'rb').read()
i = 2
while i < len(d):
    if d[i] != 0xFF: i += 1; continue
    m = d[i+1]
    if m in (0xC0, 0xC1, 0xC2):
        h, w = struct.unpack('>HH', d[i+5:i+9])
        ok = "OK" if abs(w/h - 2.0) < 0.02 else "ZŁE PROPORCJE"
        print(f"{sys.argv[1]:<14} {w}×{h}  {w/h:.3f}  {ok}")
        break
    if m in (0xD8, 0xD9) or 0xD0 <= m <= 0xD7: i += 2; continue
    i += 2 + struct.unpack('>H', d[i+2:i+4])[0]
PY
done
```

Oczekiwane: cztery linijki `OK`. Merkury musi wyjść `1024×512  2.000  OK` — ta wartość
została zmierzona przy pisaniu planu i służy za punkt odniesienia. Jeśli wychodzi inaczej,
pobrał się inny plik.

- [ ] **Krok 3: Pył pierwszego planu w TSL**

To jest miejsce, w którym WebGPU zarabia na siebie. Nazwy funkcji TSL sprawdzone
w `three.tsl.js` wersji 0.185.1 — wszystkie użyte niżej należą do 638 eksportów tego pliku.

```js
import { Fn, vec3, float, uniform, instanceIndex, hash, time, positionLocal, mix, smoothstep } from "three/tsl";
import * as THREE from "three";

/* Pył daje zdjęciom paralaksę. Bez niego mgławice są płaską tapetą i cały kosmos
   wygląda na namalowany na szybie tuż przed kamerą. */
export function zbudujPyl(ile = 20000) {
  const poz = new Float32Array(ile * 3);
  const ZASIEG = 4000;
  for (let i = 0; i < ile; i++) {
    /* Deterministycznie z indeksu, nie z Math.random() — ten sam pył w każdym uruchomieniu. */
    const a = Math.sin(i * 12.9898) * 43758.5453;
    const b = Math.sin(i * 78.233)  * 43758.5453;
    const c = Math.sin(i * 39.425)  * 43758.5453;
    poz[i * 3]     = ((a - Math.floor(a)) - 0.5) * ZASIEG;
    poz[i * 3 + 1] = ((b - Math.floor(b)) - 0.5) * ZASIEG;
    poz[i * 3 + 2] = ((c - Math.floor(c)) - 0.5) * ZASIEG;
  }
  const geo = new THREE.BufferGeometry();
  geo.setAttribute("position", new THREE.BufferAttribute(poz, 3));

  const mat = new THREE.PointsNodeMaterial({
    transparent: true, depthWrite: false, blending: THREE.AdditiveBlending,
  });
  const jasnosc = uniform(0.55);
  mat.colorNode = vec3(0.55, 0.72, 0.85).mul(jasnosc).mul(
    hash(instanceIndex).mul(0.6).add(0.4)
  );
  mat.opacityNode = smoothstep(0.0, 1.0, hash(instanceIndex.add(7))).mul(0.5);

  const punkty = new THREE.Points(geo, mat);
  punkty.name = "pyl";
  punkty.frustumCulled = false;
  scene.add(punkty);

  /* Pył podąża za kamerą, żeby nigdy się nie skończył — przesuwamy chmurę skokowo
     o pełny zasięg, gdy kamera wyjdzie poza jej połowę. Dzięki temu 20 000 punktów
     wystarcza na cały układ zamiast wypełniać 9000 metrów promienia. */
  function aktualizuj(kamera) {
    punkty.position.x = Math.round(kamera.position.x / ZASIEG) * ZASIEG;
    punkty.position.y = Math.round(kamera.position.y / ZASIEG) * ZASIEG;
    punkty.position.z = Math.round(kamera.position.z / ZASIEG) * ZASIEG;
  }
  return { punkty, aktualizuj, jasnosc };
}
```

- [ ] **Krok 2: Deterministyczne rozmieszczenie na powłoce**

```js
/* Ziarno z identyfikatora projektu. Math.random() jest zabroniony: gracz ma móc wrócić
   do zapamiętanego celu, a przy losowaniu ten sam projekt leżałby gdzie indziej
   po każdym odświeżeniu. */
function ziarno(id) {
  let h = 2166136261;
  for (let i = 0; i < id.length; i++) { h ^= id.charCodeAt(i); h = Math.imul(h, 16777619); }
  return ((h >>> 0) % 100000) / 100000;   // 0..1
}

/* Sondy jednej epoki leżą na wspólnym promieniu, rozłożone po kącie w kolejności daty.
   Wysokość rozrzucona ziarnem, żeby powłoka była pasem, a nie płaskim pierścieniem. */
function pozycjaSondy(projekt, indeks, ile, powloka) {
  const kat = (indeks / Math.max(ile, 1)) * Math.PI * 2;
  const r = powloka.promien;
  const y = (ziarno(projekt.id) - 0.5) * r * 0.16;
  return new THREE.Vector3(Math.cos(kat) * r, y, Math.sin(kat) * r);
}
```

- [ ] **Krok 2: Lot 6DOF na kwaternionie**

```js
/* Orientacja kwaternionem, nie parą kątów. Para yaw/pitch traci stopień swobody przy
   locie prosto w górę lub w dół — a w kosmosie nie ma "góry", więc gracz tam trafi
   w pierwszej minucie i sterowanie zacznie się blokować bez widocznej przyczyny. */
const obrot = new THREE.Quaternion();
const chwilowy = new THREE.Quaternion();
const OS_X = new THREE.Vector3(1, 0, 0);
const OS_Y = new THREE.Vector3(0, 1, 0);
const OS_Z = new THREE.Vector3(0, 0, 1);

const TEMPO_OBROTU = 1.8;     // rad/s przy pełnym wychyleniu
const TEMPO_MAX = 900;        // m/s w pustce
const TEMPO_MIN = 90;         // m/s blisko obiektów
const WYGLADZANIE = 4.0;      // im wyżej, tym szybciej rakieta nadąża za zamiarem

function aktualizuj(dt) {
  // Obrót: myszka steruje pochyleniem i odchyleniem, Q/E obrotem wokół osi lotu.
  chwilowy.setFromAxisAngle(OS_X, -wejscie.pochylenie * TEMPO_OBROTU * dt);
  obrot.multiply(chwilowy);
  chwilowy.setFromAxisAngle(OS_Y, -wejscie.odchylenie * TEMPO_OBROTU * dt);
  obrot.multiply(chwilowy);
  chwilowy.setFromAxisAngle(OS_Z, wejscie.przechyl * TEMPO_OBROTU * dt);
  obrot.multiply(chwilowy);
  obrot.normalize();          // bez tego kwaternion dryfuje i skaluje scenę

  /* Prędkość skalowana odległością do najbliższego obiektu: wolno przy sondach
     i planetach, szybko w pustce. Bez tego przelot z powłoki 1 na 6 (7800 metrów)
     trwałby ponad minutę i byłby karą, a nie podróżą. */
  const blisko = dystansDoNajblizszego(pozycja);
  const docelowe = THREE.MathUtils.clamp(
    THREE.MathUtils.mapLinear(blisko, 120, 1500, TEMPO_MIN, TEMPO_MAX),
    TEMPO_MIN, TEMPO_MAX
  );
  tempo += (docelowe * wejscie.ciag - tempo) * Math.min(1, WYGLADZANIE * dt);

  kierunek.set(0, 0, -1).applyQuaternion(obrot);
  pozycja.addScaledVector(kierunek, tempo * dt);
}
```
